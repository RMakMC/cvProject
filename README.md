EN: This repository contains all the data needed to enable my computer vision and PIR sensor-based lighting control system. 
The system board (.lay6) opens in sprint-layout, and the main code is in the human.py file. The Arduino code is in ArduinoCodeExp.
I printed the case on a 3D printer in the form of a box with an overhead socket. I advise you to make a more adequate version.
